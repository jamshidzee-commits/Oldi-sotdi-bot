# oldi-sotdi-bot
Telegram-бот объявлений для канала **Oldi sotdi** (@oldisotdichennel), бот @Oldisotdichennel_bot.

**Как работает**
- Продавец заполняет форму в боте: название, категория, цена, адрес, ориентир, 1–5 фото.
- Номер телефона берётся только кнопкой «Отправить номер» (Telegram сам подтверждает владельца), вручную вписать нельзя.
- Каждое объявление приходит админу (владельцу канала) с кнопками «Одобрить / Отклонить».
- Форму можно заполнить сразу, но на проверку админу объявление уходит только после того, как человек пригласит в канал 5 человек по личной ссылке (считаются только те, кто остался в канале). До этого оно хранится как «ожидает». Открывается навсегда.
- «Мои объявления» → «Продано»: в посте остаётся метка «ПРОДАНО», телефон/адрес/ссылка на продавца убираются.
- Комментарии работают через привязанную к каналу группу обсуждений.
- Языки бота: узбекский (латиница) и русский.

**Секреты и переменные репозитория** (Settings → Secrets and variables → Actions)
- Secret `TELEGRAM_BOT_TOKEN` — токен от @BotFather (обязательно).
- Variables (необязательно): `CHANNEL_ID` (по умолчанию @oldisotdichennel), `ADMIN_CHAT_ID` (по умолчанию владелец канала определяется сам), `INVITES_NEEDED` (5), `DAILY_LIMIT` (3 объявления в сутки).

**Запуск:** Actions → «Oldi sotdi bot» → Run workflow. Дальше бот перезапускает сам себя каждые ~55 минут.

Телефон в `state.json` хранится только в зашифрованном виде и только пока объявление ждёт одобрения.
