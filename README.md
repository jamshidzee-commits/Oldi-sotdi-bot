# oldi-sotdi-bot
Telegram-бот объявлений для канала **Oldi sotdi** (@oldisotdichennel), бот @Oldisotdichennel_bot.

**Как работает**
- Продавец заполняет форму в боте: название, категория, цена, адрес, ориентир, 1–5 фото.
- Номер телефона берётся только кнопкой «Отправить номер» (Telegram сам подтверждает владельца), вручную вписать нельзя.
- Каждое объявление приходит админу (владельцу канала) с кнопками «Одобрить / Отклонить».
- Форму можно заполнить сразу. Пригласив в канал 5 человек по личной ссылке (считаются только оставшиеся в канале), человек получает «пакет»: 24 часа и до 3 объявлений. После этого для новых объявлений нужно снова пригласить 5 НОВЫХ человек. Пока пакета нет, объявление хранится как «ожидает» и уходит админу на проверку само, когда пакет откроется. Отклонённое админом объявление в пакет не засчитывается.
- «Мои объявления»: ✏️ изменить (название, цена, адрес, ориентир, категория; пост в канале обновляется), 🗑 удалить, ✅ продано. Фото/видео меняются удалением и повторной подачей. Об изменении живого поста админу приходит уведомление с кнопкой «Удалить пост».
- «Продано»: в посте остаётся метка «ПРОДАНО», телефон/адрес/ссылка на продавца убираются.
- Комментарии работают через привязанную к каналу группу обсуждений.
- Языки бота: узбекский (латиница) и русский.

**Секреты и переменные репозитория** (Settings → Secrets and variables → Actions)
- Secret `TELEGRAM_BOT_TOKEN` — токен от @BotFather (обязательно).
- Variables (необязательно): `CHANNEL_ID` (по умолчанию @oldisotdichennel), `ADMIN_CHAT_ID` (по умолчанию владелец канала определяется сам), `INVITES_NEEDED` (5), `DAILY_LIMIT` (объявлений в одном пакете, по умолчанию 3).

**Запуск:** Actions → «Oldi sotdi bot» → Run workflow. Дальше бот перезапускает сам себя каждые ~55 минут.

Телефон в `state.json` хранится только в зашифрованном виде и только пока объявление ждёт одобрения.

**Для знакомых (без приглашений).** Админ отправляет боту `/vip`: бот даёт одноразовую ссылку, которую можно переслать человеку. Тот, кто откроет её первым, получает доступ без приглашений (до 3 объявлений в сутки, каждое всё равно идёт админу на одобрение). `/vips` показывает список, `/unvip ID` отключает доступ.
